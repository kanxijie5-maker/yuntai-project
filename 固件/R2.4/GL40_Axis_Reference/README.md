# GL40 单轴控制移植参考

这里整理了 GL40 在 1 rpm 爬行、正反换向和小角定位时的控制代码，供三轴云台按轴移植。11 月 28 日的复盘给出了改动前后的实测波形、换向延迟和定位过冲。[低速与换向复盘（PDF）](../Driver_Bench/GL40_单轴低速与换向调试复盘_2026-11-28.pdf)

实测使用 R2.4 驱动板、GD32F303、DRV8316CR、GL40 KV70（14 极对）、AS5048A 和 12 V 电源，电机空载。PWM 为 20 kHz，电流环为 10 kHz，速度及位置环为 1 kHz。[台架工程](../Driver_Bench/README.md) · [11 月 27 日低速抖动复盘（PDF）](../Driver_Bench/GL40_低转速抖动调试复盘_2026-11-27.pdf)

## 从问题找到代码

| 台架现象 | 保留下来的做法与代码入口 | 实测结果与适用条件 |
|---|---|---|
| 1 rpm 从零起步冲一下，转到某些角度又停顿 | `axis_command` 选爬行增益，`ramp_rpm` 以 0.5 rad/s² 起步。`estimate_speed` 在前 350 ms 用 4 ms 位移估速，随后换为 16 ms 窗口。原始机械角在 `cogging_current` 中查表插值，作为速度 PI 的电流前馈。 | 两版都启用 D 表时，各方向 5 圈中反复慢于 0.6 rpm 的角区，正转由 3 个降为 0 个，反转由 5 个降为 0 个。单圈仍可出现短时降速。 |
| 正反向过零停顿，快速换向冲过目标速度 | `ramp_rpm` 在爬行换向时缩短测速窗口，按给定变化逐拍修正速度 PI 积分；`estimate_speed` 在绝对给定达到 5 rpm 时改用 2 ms 窗口。 | ±1 rpm 换向后沿新方向净走 0.25° 的中位时间，正切反由 81 降至 50 ms，反切正由 85 降至 65 ms。摩擦电流修正系数来自这台裸轴。 |
| 给 1° 后迟迟不动，大步定位时启停冲击 | `position_speed_ref` 用两级约 55 ms 的平滑轨迹，小角微调加入有界速度前馈。大步过渡和静止保持分别用短、长测速窗口。 | 最终版 ±1° 阶跃走出前 0.1° 的中位时间，负向 62 ms、正向 60 ms。另一轮大步定位中最大角加速度由 2146 降至 754 °/s²，进入 ±0.2° 的中位时间由 447 延至 695 ms。 |
| 低速时相电流过零易抖，保持时电流波动 | `modulate` 按 Iq 给定重建三相电流方向，在 ±40 mA 内平滑施加死区电压补偿。连续 rpm 模式用两拍 d/q 电流均值，位置和直接 Iq 模式用本拍值；过流保护在滤波前执行。 | 原固件在 rpm 与位置模式补偿，上限为占空比的 1%，对应 20 kHz 下 0.50 µs。大步定位最后 400 ms 内，Iq 给定标准差的中位数由 10.53 降至 3.89 mA。另做的 60 s 保持试验未观察到漂移量下降。 |
| 从不同齿槽位置上电，对齐偶发回程超差；断电后找不到机械零位 | `align_step` 让两次采基准前的磁场都从同一侧接近，继续检查相电流、正扫幅度和回程。`axis_set_home` 与 `axis_position_counts` 让机械零位独立于电角零点。`home_record.h` 识别两份记录中最近一次有效写入。 | 保留 74 码回程边界。AS5048A 单圈零位可跨 16383/0 回绕恢复。每轴分别保存零位、方向和对应记录，上电运动前仍需重新对齐。 |
| 关桥后零电流读数贴近 3.3 V，无法校零 | 板级先确认六路输入低、主输出关闭，再释放 DRVOFF 并复查刹车和 SPI 状态。`current_zero_sample` 对三相连续 256 组合格数据分别求零偏，中途失效会清空累计。 | 这块板关断时曾读到 3836/4074/4095 码，高阻准备后回到约 2074 码。板级操作顺序可对照原工程的 `prepare_idle`、`bench_hiz_prepare` 和 `bridge_set`。 |

## 接入三轴云台

1. 目标工程加入 `foc.c` 和 `foc.h`。它们仅依赖标准 C 库。若要复用 `rpm1`、`pos` 等串口命令，再加入 `commands.c` 和 `decimal.h`。`tests` 供主机运行。
2. 为三个轴分别声明一个 `axis_t`，在上电时各初始化一次。新装的三个轴默认传 `NULL`。只有确认仍为原电机、原磁铁与原编码器角度关系的那一轴，才可在初始化时传 `&gl40_table_d`（包含 `gl40_cogging_table.h`）。同型号、同方向也可能有不同的齿槽相位。另行标定的表以绝对机械角原码递增顺序存放 512 个区间中心的有符号电流，单位 mA，`direction` 填标定时正转对应的编码器方向。
3. 每轴每 100 µs 送入同一采样周期的三相电流（A）、母线电压（V）、14 位原始轴角和外设故障位，调用 `axis_step`。主控给定和 `axis_step` 在同一控制上下文执行。串口或 CAN 中断收到命令时先送信箱。
4. 已有整机姿态环时，由主控计算每轴 Iq（A），驱动侧用 `SET_IQ` 接收。这样复用的是电角对齐、编码器处理和电流 FOC。轴端独立做匀速与定位时，分别使用 `SET_RPM` 与 `SET_POS`。`SET_RPM` 的 C 接口单位为 rad/s，串口 `rpm` 的单位为转/分。`SET_SPEED` 沿用原台架的直接速度给定。两级位置轨迹适合单轴设点，整机姿态反馈和三轴力矩分配由主控负责。
5. `ready` 由板级驱动根据有效采样、零偏、驱动状态及节拍产生。每拍检查 `axis.mode`，仅在 ALIGN、JOG、CURRENT、SPEED、POSITION 下按安全时序提交 `duty[3]`。IDLE、FAULT、硬件刹车或提交失败时由板级实际关桥。R2.4 原板负责 TP8、POEN、刹车锁存、35%～65% 的占空比检查及超时关桥。50% 的软件中性占空比本身不能关桥。
6. `SET_IQ`、`SET_SPEED`、`SET_POS` 需要新给定或 `KEEP` 续期，内部上限为 500 ms。`SET_RPM` 保留台架单发持续转动的语义。联机运行沿用主控链路自己的看门狗，例如 R2.4 的 CAN 驱动在 10 ms 失联时对出力轴调用 `axis_trip` 并关桥。主动保持时接续位置命令；`STOP` 后轴可自由回弹。

以下是三轴初始化示例。表指针由调用方提供，编码器历史、积分、故障及零位都存放在各自的 `axis_t` 中。

```c
#include <stddef.h>
#include "foc.h"

static axis_t axes[3];

void gimbal_axes_init(void)
{
    for(unsigned i = 0; i < 3; ++i)
        axis_init(&axes[i], NULL);
}
```

## 换板、加负载后先核对什么

- **时序与采样**　P3 的现有设计为 30 kHz PWM、10 kHz 电流环。测速与轨迹按实际 1 ms 外环复核。ADC 触发位置、三相低侧共同导通窗口、死区等效占空比以及三轴中断总耗时，须按新板的定时器、驱动和采样电路重新核定。R2.4 的电流采样增益、故障电平和 12 位原码窗口也属于板级参数。
- **机械负载**　14 极对、±0.35 A Iq 上限、0.65 A 相电流跳闸线、速度和位置增益、爬行摩擦修正，均对应原台架。换轴重查相序、编码器方向和每轴机械零位；装臂后分别复测正反换向、不同起点的小阶跃、持续保持的漂移和温升。
- **复测顺序**　先在 PWM 关闭时核对传感器和零偏，再逐轴对齐。空载比对 ±1 rpm 整圈、±1/10/30/50 rpm 换向、±1° 阶跃和 60 s 保持。带载后追加三轴同时出力的采样时序、行程限位和失联关桥验收。

## 编译与校验

在本目录使用 C11 编译器运行随附回归。覆盖正反编码器安装、齿槽表整圈插值、零位回绕、起步、换向、位置保持、原始过流保护及三轴实例隔离。

```sh
cc -std=c11 -O2 -Wall -Wextra foc.c commands.c tests/test_axis.c -lm -o test_axis
./test_axis
```

Windows 可在 Visual Studio x64 本机工具命令行运行。

```bat
cl /nologo /std:c11 /utf-8 /O2 /W4 /WX /D_CRT_SECURE_NO_WARNINGS foc.c commands.c tests\test_axis.c /Fe:test_axis.exe
test_axis.exe
```

整理时，参考代码通过主机回归，并使用 Keil Arm Compiler 5 编译为 Cortex-M4F 目标文件。另以同一电机模型、两种编码器方向、原 D 表和同一组指令，逐拍比较原台架版与参考版的模式、轴角、反馈速度、速度给定、Iq 给定与反馈、Id、Vd/Vq、齿槽前馈和三相占空比。248,600 个控制周期、每周期 13 项逐字节一致。实测结论来自原 GL40 空载台架；参考代码自身完成的是软件验证。
